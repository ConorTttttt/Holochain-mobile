# H2HC phone benchmark

Run 20261023-190414 on local (Linux 7.0.0-38-generic x86_64). 3 full-arc authorities, 30 iterations per operation. Phone builds from `target`.

## Startup

| Configuration | Process start to conductor | Install | Enable | First zome call | Network ready |
|---|---|---|---|---|---|
| h2hc + wasmi | 1.54 s | 84.0 ms | 891.3 ms | 63.3 ms | 136.0 ms |
| h2hc + cranelift | 1.59 s | 610.3 ms | 67.5 ms | 851.5 ms | 1.07 s |
