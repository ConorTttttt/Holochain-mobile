# H2HC phone benchmark

Run 20261023-192829 on local (Linux 7.0.0-38-generic x86_64). 3 full-arc authorities, 30 iterations per operation. Phone builds from `target`.

## Startup

| Configuration | Process start to conductor | Install | Enable | First zome call | Network ready |
|---|---|---|---|---|---|
| h2hc + wasmi | 1.56 s | 132.4 ms | 37.2 ms | 125.3 ms | 235.9 ms |
| h2hc + cranelift | 1.57 s | 579.3 ms | 57.4 ms | 821.0 ms | 877.3 ms |
