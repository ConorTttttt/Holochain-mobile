# H2HC phone benchmark

Run 20261023-221957 on android (Linux 7.0.0-38-generic x86_64). 3 full-arc authorities, 20 iterations per operation. Phone builds from `target`.

Phones used Holochain's in-memory test keystore: Android does not let the adb shell user bind Lair's Unix socket. Startup therefore leaves out Lair's passphrase hashing, and scenarios that restart the phone are skipped.

## Startup

| Configuration | Process start to conductor | Install | Enable | First zome call | Network ready |
|---|---|---|---|---|---|
| h2hc + wasmi | 2.03 s | 335.0 ms | 151.9 ms | 232.4 ms | 839.1 ms |
| h2hc + cranelift | 2.61 s | 1.56 s | 222.2 ms | 1.93 s | 2.45 s |
| kitsune2 + wasmi | 2.15 s | 340.9 ms | 313.9 ms | 209.3 ms | 7.41 s |
